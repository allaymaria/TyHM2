# 📚 Clase 5: Fotografía

### Tipos de Fotografías
Cada una diferenciada por lo que se necesita para tomar una buena foto.
* Playa - Nieve
* Fiesta Interior
* Paisaje
* Retrato
* Nocturna (Fuegos Artificiales)
* Comida

### Problemas
* Aberración cromática
* Difracción

## Ley de los tercios
La regla de los tercios es una técnica de composición visual que divide una imagen en nueve partes iguales mediante dos líneas horizontales y dos verticales.
