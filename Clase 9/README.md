# 📚 Clase 9: Dinámica de sistemas

---

## 📌 Resumen de la Clase

En esta clase se introdujeron los fundamentos teóricos y prácticos de la **Dinámica de Sistemas**. Aprendimos a identificar y conceptualizar las variables internas (endógenas) y externas (exógenas) que componen la estructura de un sistema operativo, industrial o de servicios. Durante la parte práctica, utilizamos el programa **Vensim PLE** para comenzar a modelar diagramas de flujo y niveles que permitan simular el comportamiento de estos sistemas a lo largo del tiempo.

---

## 🔄 Concepto de Dinámica de Sistemas

La **Dinámica de Sistemas** es una metodología desarrollada por *Jay W. Forrester* en el Instituto Tecnológico de Massachusetts (MIT) a mediados de la década de 1950. Está diseñada para comprender, estructurar y simular el comportamiento de sistemas complejos interconectados a lo largo del tiempo.

---

## 🔲 Identificación de Variables del Sistema

Para el modelado de un proceso o proyecto, es fundamental delimitar las variables que pertenecen a la estructura del modelo (*dentro del límite o frontera del sistema*) de aquellas que actúan de manera externa (*fuera del sistema*):

### 📥 Dentro del Sistema (Variables Endógenas / Controlables)

* **Recursos Financieros:** Dinero disponible, flujos de caja.
* **Leadtime:** Tiempo transcurrido desde que se efectúa el pago/pedido hasta que se recibe el producto o insumo.
* **Materia Prima e Insumos:** Stocks y flujos de materiales.
* **Instalaciones y Capacidad:** Planta física, maquinaria y equipos.
* **Mano de Obra (Workforce):** Horas-hombre disponibles, dotación de personal.
* **Rendimiento Operativo:** Productividad, disposición de layout.
* **Capacidad de Producción ($Q$):**
  * *Ejemplo Bodega:* Cantidad de botellas producidas al año.
  * *Ejemplo Transporte:* Cantidad de pasajeros transportados al día.

### 📤 Fuera del Sistema (Variables Exógenas / Entorno)

* **Políticas Fiscales:** Impuestos, cargas tributarias.
* **Factores Sociales:** Nivel de escolaridad, contexto socioeconómico.
* **Servicios de Terceros / Secundarios:** Comedor/buffet, servicios auxiliares no críticos.

## 💻 Simulación con Vensim PLE

**Vensim PLE (Personal Learning Edition)** es la herramienta de software empleada para la construcción de diagramas de causalidad (*Causal Loop Diagrams*) y diagramas de stock y flujo (*Forrester Diagrams*), permitiendo simular cómo se modifica el comportamiento del sistema ante cambios en sus parámetros.
