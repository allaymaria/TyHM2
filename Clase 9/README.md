# Dinámica de Sistemas

Dinámica de sistemas (creada por Jay W. Forrester en el MIT a mediados de la década de 1950) es una metodología para entender cómo se comportan los sistemas complejos a lo largo del tiempo.

**Dentro del Cuadrado**
* Dinero
* Leadtime: tiempo desde que pago hasta que obtengo el producto
* Materia Prima
* Instalaciones
* Horas Hombre
* Work force
* Productividad
* Layout
* Q: producción (por ejemplo: Bodega -> Cantidad de botellas al año; Transporte -> Cantidad de pasajeros al día)

**Fuera del Cuadrado**
* Impuestos
* Escolaridad
* Pancho-Buffet
