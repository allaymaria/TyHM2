# 📚 Clase 6: Método de Decisión AHP y Metadatos de Fotografías

## Consigna 
Aplicar método AHP

En algún capítulo donde haya conflicto (o sino inventar un conflicto)

1. Definir el objetivo "Mejor proyecto"
2. Escribir las alternativas "Hay que salir a buscar alternativas"
3. Criterios (debajo del objetivo principal): Datos, Viabilidad, Alineación vocacional, Aporte de ingeniería y Reputación en el CV.
4. Comparar las opciones respecto a los criterios, le das objetividad al criterio.
5. Definimos la matriz de pesos, comparamos los criterios con los otros criterios.
6. Obtenemos un gráfico donde visualizamos cual es mayor en cada criterio, que criterio pesa más y finalmente cual es la mejor opción de las alternativas. Al mover los pesos realizamos un análisis de sensibilidad y podemos visualizar como se modifica (o no) el ranking.
